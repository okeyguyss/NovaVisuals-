# NovaVisuals — визуалы для Minecraft 1.16.5 (Forge)

Клиентский мод. Работает на любом сервере, включая ReallyWorld: на сервер ставить ничего не нужно.

**Меню — Right Shift** (клавишу можно сменить в Настройки → Управление → NovaVisuals).

## Что внутри

| Модуль | Что делает |
|---|---|
| **Авто-спринт** | Бег без зажатия Ctrl. Игра сама проверяет голод, присед и т.д., поэтому это обычный ванильный спринт. |
| **Таргет HUD** | Панель противника: голова скина (у мобов — модель), ник, HP цифрами и полоской с «следом» урона, золотая полоска поглощения, броня + предметы в руках, «Победа / Проигрыш / Ничья». Позиция X/Y и размер настраиваются. Опция «HP из скорборда» берёт HP из цифры под ником (как на RW). |
| **Руки (ViewModel)** | Отдельно для правой и левой руки: влево/вправо, вниз/вверх, ближе/дальше, наклон, поворот, крен, размер. Можно скрыть левую руку. Кнопка «Сбросить руки». |
| **Прицел** | Кастомный прицел: круг, квадрат, крест или точка. Размер, толщина, отступ, точка в центре, обводка, расширение при беге, кольцо перезарядки удара, цвет (тема / белый / свой RGB). |
| **Чистый экран** | Полностью убирает огонь с экрана, тряску камеры при ударе, брызги и спирали частиц зелий (отравление и любые другие, когда в тебя кидают), искажение экрана от тошноты. Опционально: оверлей воды, «блок в лицо», тыкву, эффект портала, боссбар. |
| **HUD** | Ватермарка с FPS, пингом и временем, координаты (+ перевод в ад/мир), список включённых модулей справа. |
| **Яркость** | Fullbright. |
| **Интерфейс** | Тема: фиолетовая, голубая, розовая, мятная, красная, радуга; скорость переливания; затемнение фона. |

### Управление в меню
- ЛКМ по модулю — открыть его настройки; ЛКМ по переключателю или ПКМ по модулю — вкл/выкл.
- Слайдеры тянутся мышкой, **ПКМ по слайдеру — сброс** к стандарту.
- Режимы: ЛКМ — следующий, ПКМ — предыдущий.
- Колёсико — прокрутка настроек.
- Меню не ставит игру на паузу и не закрывает экран: руки и Target HUD видно вживую, пока двигаешь слайдеры.

Все настройки сохраняются в `.minecraft/config/novavisuals.json`.

## Как получить готовый .jar

### Способ 1 — без установки чего-либо (GitHub)
1. Создай пустой репозиторий на github.com.
2. Загрузи туда **всё содержимое** этой папки (кнопка *Add file → Upload files*, перетащи все файлы и папки, включая `.github`).
3. Открой вкладку **Actions** — сборка запустится сама (около 5–10 минут).
4. Открой завершённую сборку → внизу в **Artifacts** скачай `NovaVisuals-1.16.5` → внутри `NovaVisuals-1.16.5-1.0.0.jar`.

### Способ 2 — на своём компьютере (Windows)
1. Установи Java 17: https://adoptium.net (Temurin 17, MSI-установщик).
2. Открой папку проекта, в адресной строке проводника напиши `cmd` и нажми Enter.
3. Выполни:
   ```
   gradlew.bat build
   ```
   Первый раз скачается Minecraft и Forge (5–15 минут).
4. Готовый мод: `build\libs\NovaVisuals-1.16.5-1.0.0.jar`.

Хочешь сразу проверить в игре без лаунчера — `gradlew.bat runClient`.

## Установка
1. Поставь **Forge 1.16.5** (36.2.x) — https://files.minecraftforge.net/net/minecraftforge/forge/index_1.16.5.html
2. Кинь `.jar` в папку `.minecraft/mods`.
3. Запусти профиль Forge 1.16.5, зайди на сервер, нажми Right Shift.

## Совместимость
- Мод чисто визуальный + авто-спринт (зажимает ванильную клавишу бега). Пакетов на сервер не шлёт, движение не подменяет.
- Правила серверов меняются — перед игрой на ReallyWorld глянь их правила про разрешённые моды.
- Если стоит OptiFine — должно работать вместе (обычный Forge-мод).
